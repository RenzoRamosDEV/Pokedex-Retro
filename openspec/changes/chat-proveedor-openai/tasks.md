# Tareas: chat también con clave de OpenAI (1.3.0)

Reglas para todos los commits: Conventional Commits con tipo en inglés y descripción en español, imperativo, < 72 caracteres, sin punto final, sin `Co-Authored-By` ni mención a IA, identidad git sin cambios, hook de pre-commit sin `--no-verify`. Los asuntos son exactamente los indicados en cada tarea. El avance de casillas entra en el commit de archivo. Nunca se versionan `requirements/`, `.claude/` ni `.serena/`.

TDD obligatorio para toda lógica: **Rojo** (test que falla por el motivo esperado, comprobado ejecutándolo), **Verde** (mínimo para pasar), **Refactor** (con los tests en verde). Tests con `node:test`, sin red, rápidos; entradas por particiones de equivalencia, valores límite, ficheros dorados y adivinación de errores; fakes antes que mocks. Ningún test usa la red real ni una clave real.

Mutación: cada ejecución de Stryker ≤ 180 s (los scripts llevan `timeout 180`; medir con `time`); ≥ 95 % en `core`, `mappers` y `site/js/chat` (incluidos ambos adaptadores), ≥ 85 % en `ui` y `mcp/src`, o supervivientes justificados en el PR. Ningún `thresholds.break` se baja. Para iterar sobre el diff se puede usar `reports/stryker-*.config.json` (ignorado por git) con `mutate` limitado a los ficheros cambiados.

El puerto 4173 de esta máquina pertenece a otro proceso: no usarlo ni matarlo. El e2e usa 4180 (`playwright.config.js`); la verificación manual usa `PORT=4181`.
